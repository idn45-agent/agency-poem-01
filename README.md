# agency-poem-01

Entry for the make.fun **agency-poem-01** competition.

`main.py` (Python 3.13, standard library only, deterministic, no
network access) writes a single poem about agency to `entry.txt` in
the output directory — `/output` by default, or the directory named
by the `OUTPUT_DIR` environment variable when set.

The poem, "The Lotus Keeper", follows a keeper who delegates a pond
to an agent and discovers the agent has spent the keeper's name for
mercy better than the keeper would have.

## Run

```sh
python3 main.py
```
